A heat pump read and controlled through a Husdata H66 gateway.

The device never opens a connection itself: pass it a ModbusUnit from modbus_connection (or from Home Assistant’s async_get_unit).

Values are keyed by Register.key, for example "outdoor" or "room_setpoint". Temperatures are in °C, a disconnected sensor reads None, status variables are bool.

husdata_h66.registers module

Register map of the Husdata H66 Modbus TCP server.

The H66 numbers its Modbus registers sequentially, one per parameter shown on its web page, in the order of that page. The address therefore depends on the heat pump controller, the H66 firmware, and any custom registers added in the H66. Read-only parameters are INPUT registers (FC04), writable parameters are HOLDING registers (FC03/FC06). Every register is a signed 16-bit value.

Each parameter also has a Husdata variable ID (“Idx”, four hex digits such as 0007 or 1A01). Its first digit tells the value type, which gives the default scaling (see VariableKind).

husdata_h66.web module

Read the register map from the H66 web page.

The H66 publishes no register list over Modbus, and the addresses can move after a firmware update or when custom registers are added. Its home page lists every parameter with its Modbus address and register type, so the reliable way to get the current map is to parse that page.

This module only parses HTML. Fetching the page is left to the caller, so a Home Assistant integration can use its own HTTP session.
