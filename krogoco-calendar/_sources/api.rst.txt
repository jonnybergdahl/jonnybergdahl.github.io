API reference
=============

:class:`~krogoco_calendar.KrogocoIcs` fetches a calendar page and builds the
ICS data. Each scraped entry is a :class:`~krogoco_calendar.CalendarEvent`,
which you get from :meth:`~krogoco_calendar.KrogocoIcs.scrape_events` if you
want the events without the ICS step.
