BLE transport

Install with pip install improv-client[ble].

Find devices with discover(), or pass a bleak.backends.device.BLEDevice from your own scanner (for example the Home Assistant Bluetooth integration) to ImprovBleClient.

Devices may start in AUTHORIZATION_REQUIRED and need a button press before they accept credentials. Wait for that with wait_for_state().

Commands that the device’s capabilities don’t include raise ImprovNotSupportedError without being sent. The device name commands have no capability bit and are always sent.

Improv Wi-Fi over Bluetooth Low Energy.

Requires the ble extra: pip install improv-client[ble]. Built on bleak and bleak-retry-connector.

The client connects on demand: every command connects first if needed, and the connection closes after a period without commands (90 seconds by default). This follows the design of py-improv-ble-client (MIT), as do the retrying connector and matching results to commands by command id.

Example:

import asyncio
from improv_client.ble import ImprovBleClient, discover
from improv_client.protocol import State

async def main():
    devices = await discover()
    if not devices:
        return
    async with ImprovBleClient(devices[0].device) as client:
        if client.state is State.AUTHORIZATION_REQUIRED:
            print("Press the button on the device")
            await client.wait_for_state(State.AUTHORIZED, timeout=60)
        url = await client.provision("MyWirelessAP", "mysecurepassword")
        print("Provisioned, next step:", url)

asyncio.run(main())

class improv_client.ble.ImprovBleClient(device, *, timeout=10.0, idle_disconnect_delay=90.0, disconnected_callback=None)[source]

Bases: ImprovClient

Client for an Improv Wi-Fi device over BLE.

Commands connect automatically, so calling connect() first is optional.

Parameters:

  • device (BLEDevice) – The device, from discover(), find_device() or a bleak scanner.

  • timeout (float) – Default time in seconds to wait for an answer.

  • idle_disconnect_delay (float | None) – Seconds without commands before disconnecting, or None to stay connected until disconnect().

  • disconnected_callback (Callable[[ImprovBleClient], None] | None) – Called with the client whenever the connection closes, including idle and explicit disconnects.

async wait_for_state(*states, timeout=None)

Wait until the device reports one of states.

Returns at once if the current state already matches. On BLE, use this to wait for the user to authorize the device: await client.wait_for_state(State.AUTHORIZED, timeout=60).

Parameters:

  • timeout (float | None) – Seconds to wait, or None to wait forever.

  • states (State)

Returns:

The matching state.

Raises:

  • ImprovTimeoutError – If no matching state arrives in time.

  • ImprovConnectionError – If the connection is lost while waiting.

Return type:

State
