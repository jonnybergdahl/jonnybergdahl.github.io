Serial transport

Install with pip install improv-client[serial].

The device must run Improv on its serial port, which ESPHome does on the USB serial port by default (improv_serial:). Improv frames share the port with the device log; the client skips everything that isn’t a valid frame.

The serial client has two commands BLE doesn’t have: request_current_state() and get_network_state(). It has no identify.

Improv Wi-Fi over a serial port.

Requires the serial extra: pip install improv-client[serial].

Example:

import asyncio
from improv_client.serial import ImprovSerialClient

async def main():
    async with ImprovSerialClient("/dev/ttyUSB0") as client:
        print(await client.request_current_state())
        print(await client.get_device_info())
        url = await client.provision("MyWirelessAP", "mysecurepassword")
        print("Provisioned, next step:", url)

asyncio.run(main())

async wait_for_state(*states, timeout=None)

Wait until the device reports one of states.

Returns at once if the current state already matches. On BLE, use this to wait for the user to authorize the device: await client.wait_for_state(State.AUTHORIZED, timeout=60).

Parameters:

  • timeout (float | None) – Seconds to wait, or None to wait forever.

  • states (State)

Returns:

Raises:
