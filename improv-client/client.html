Shared client API

Both transports derive from ImprovClient, so code that only uses the methods below works with either of them.

Shared client logic for the serial and BLE transports.

ImprovClient holds the API both transports have in common. Use ImprovSerialClient or ImprovBleClient to talk to a device.

improv_client.client.DEFAULT_TIMEOUT = 10.0

Default time to wait for an answer, in seconds.

improv_client.client.DEFAULT_PROVISION_TIMEOUT = 60.0

Default time to wait for provisioning to finish, in seconds.

improv_client.client.DEFAULT_SCAN_TIMEOUT = 30.0

Default time to wait for a Wi-Fi scan, in seconds.

Base class with the API shared by all transports.

async wait_for_state(*states, timeout=None)[source]

Wait until the device reports one of states.

Returns at once if the current state already matches. On BLE, use this to wait for the user to authorize the device: await client.wait_for_state(State.AUTHORIZED, timeout=60).

Parameters:

  • timeout (float | None) – Seconds to wait, or None to wait forever.

  • states (State)

Returns:

The matching state.

Raises:

  • ImprovTimeoutError – If no matching state arrives in time.

  • ImprovConnectionError – If the connection is lost while waiting.

Return type:

State
