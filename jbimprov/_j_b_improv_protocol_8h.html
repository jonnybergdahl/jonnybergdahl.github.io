Detailed Description

Transport independent parts of the Improv Wi-Fi protocol.

Constants, checksums, the RPC string encoding and the serial frame codec. Nothing in here depends on Arduino, so it can be unit tested on the host.

Specifications:

  • Serial: https://www.improv-wifi.com/serial/
  • BLE: https://www.improv-wifi.com/ble/
