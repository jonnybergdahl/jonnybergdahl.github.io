Detailed Description

Improv BLE transport using the ESP32 BLE library.

Owns the BLE stack (BLEDevice::init()), so don't use it together with other BLE server code. The advertised name is the device name.

◆ setAuthorizationRequired()

void JBImprovBLE::setAuthorizationRequired ( bool required)
inline

Require physical authorization before credentials are accepted.

When on, the device reports "authorization required" until authorize() is called, for example from a button press. Off by default, which lets anyone in range provision the device while it isn't connected.
