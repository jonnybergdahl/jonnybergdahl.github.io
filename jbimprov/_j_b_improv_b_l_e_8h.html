Detailed Description

Improv Wi-Fi over Bluetooth Low Energy (ESP32 only).

Works with the https://www.improv-wifi.com/ web page (Chrome, Edge), the Home Assistant Improv BLE integration and the Improv apps.

This transport is header-only, so the BLE library is only compiled into sketches that include this file.
