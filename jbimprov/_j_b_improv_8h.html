Detailed Description

Improv Wi-Fi provisioning for Arduino.

JBImprov holds the provisioning state, the device information and the Wi-Fi handling. Transports (JBImprovSerial, JBImprovBLE) carry the protocol to the client and can be combined, just like ESPHome does.

#include <JBImprov.h>
#include <JBImprovSerial.h>
JBImprov improv;
JBImprovSerial improvSerial(Serial);
void setup() {
Serial.begin(115200);
improv.setFirmware("MyFirmware", "1.0.0");
improv.addTransport(improvSerial);
improv.begin();
}
void loop() {
improv.loop();
}
