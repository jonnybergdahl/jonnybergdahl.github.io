Detailed Description

Configuration for a Home Assistant MQTT Discovery light.

Uses Home Assistant's JSON schema: commands arrive in the onCommand() handler as JSON, e.g. {"state":"ON","brightness":128}. Decode them with HaDiscovery::parseLightCommand() and report the state with HaDiscovery::publishStateLight().
