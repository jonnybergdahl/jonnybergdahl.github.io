Detailed Description

Configuration for a Home Assistant MQTT Discovery light.

With the JSON schema (the default), commands arrive in the onCommand() handler as JSON, e.g. {"state":"ON","brightness":128}. Decode them with HaDiscovery::parseLightCommand() and report the state with HaDiscovery::publishStateLight().

With HaLightSchema::Default, the light has separate topics:

  • on/off: <base>/<node_id>/<object_id>/state and .../set ("ON"/"OFF")
  • brightness: .../brightness and .../brightness/set (a number, 0..brightness_scale)
  • RGB color: .../rgb and .../rgb/set ("r,g,b", e.g. "255,0,127")
  • color temperature: .../color_temp and .../color_temp/set (kelvin)

Only the topics the color_mode needs are used. The library turns commands on any of them into the same JSON as the JSON schema before passing them to onCommand(), so parseLightCommand() and publishStateLight() work the same for both schemas.
