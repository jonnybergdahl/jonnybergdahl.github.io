Detailed Description

Publish Home Assistant MQTT Discovery config payloads via an abstract MQTT transport.

This module builds a Home Assistant MQTT device discovery payload and publishes it using a transport adapter (PubSubClient, espMqttClient or AsyncMqttClient).

Key behaviors:

  • Publishes one retained device discovery payload with all entities as components, to <discovery_prefix>/device/<node_id>/config
  • Publishes availability ("online"/"offline") and sets "offline" as the MQTT Last Will
  • Subscribes to switch and button command topics and passes commands to a handler
  • Remembers the entities and last states, and sends them again on every connect and when Home Assistant comes back online (birth message on <discovery_prefix>/status)
  • Provides default topic conventions with per-entity overrides
  • Removes single entities or the whole device
