Detailed Description

Configuration for a Home Assistant MQTT Discovery cover (blinds, garage door, ...).

Open, close and stop commands arrive in the onCommand() handler as payload_open, payload_close and payload_stop. If has_position is set, a position request arrives as a number ("0".."100", 0 = closed). Report the state ("open", "opening", "closed", "closing", "stopped") with publishState() and the position with publishStatePosition().
