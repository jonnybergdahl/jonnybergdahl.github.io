◆ availability_topic_override

const char* HaEntityCommon::availability_topic_override = nullptr

Optional override for availability topic.

If nullptr, the default is used: <baseTopicPrefix>/<node_id>/status.

Note
The MQTT Last Will only covers the default availability topic.

◆ entity_category

HaEntityCategory HaEntityCommon::entity_category = HaEntityCategory::None

Where Home Assistant shows the entity (sent as ent_cat).

Home Assistant doesn't allow Config on read-only entities (sensor, binary_sensor); the library leaves it out there and logs a warning.

◆ entity_id

const char* HaEntityCommon::entity_id = nullptr

Optional entity ID Home Assistant should use, without the domain.

Sent as def_ent_id with the domain added, so "office_temperature" on a sensor becomes sensor.office_temperature. Use lowercase letters, digits and underscores; uppercase letters are lowercased and other characters replaced with _. Home Assistant only uses it when it first creates the entity. If nullptr, Home Assistant makes one up from the device and entity names.

◆ name

const char* HaEntityCommon::name = nullptr

Entity name shown in Home Assistant, without the device name.

Home Assistant puts the device name in front, so "Temperature" on device "Office Node" shows as "Office Node Temperature". If nullptr, object_id is used.

◆ state_topic_override

const char* HaEntityCommon::state_topic_override = nullptr

Optional override for state_topic.

If nullptr, the default topic scheme is used: <baseTopicPrefix>/<node_id>/<object_id>/state.

◆ unique_id

const char* HaEntityCommon::unique_id = nullptr

Optional unique_id for Home Assistant. If nullptr, <node_id>_<object_id> is used.

Home Assistant identifies an entity by its unique_id. Set this to keep the unique_id an entity already has, e.g. when moving from other discovery code to this library, so Home Assistant keeps the entity, its history and its settings.

◆ use_device_name

bool HaEntityCommon::use_device_name = false

Mark this entity as the device's main feature.

Sends "name": null, so the entity is shown with just the device name. The name field is ignored when this is true.

◆ value_template

const char* HaEntityCommon::value_template = nullptr

Optional template that picks the state out of the state payload (sent as val_tpl).

Use it when several entities share one JSON state topic, e.g. "{{ value_json.temperature }}" together with state_topic_override. For a light with HaLightSchema::Default it's sent as stat_val_tpl and applies to the on/off state only. It's left out for buttons and JSON schema lights, which have no use for it.
